# 🐍 Cyrus Pro

**Cyrus Pro** یک ترمینال سبک و ساده برای **Kali Linux** است که با Python و `prompt_toolkit` ساخته شده است.

---

## 🇮🇷 توضیحات فارسی

### Cyrus Pro چیست؟

Cyrus Pro یک پروژه ترمینال سبک برای Kali Linux است که با هدف ساخت یک محیط ترمینالی ساده، سریع و قابل استفاده توسعه داده شده است.

این پروژه از `prompt_toolkit` استفاده می‌کند و به‌صورت مستقیم از طریق منوی برنامه‌های Kali قابل اجراست.

### ✨ امکانات

* ⚡ سبک و سریع
* 🐍 ساخته شده با Python
* 💻 رابط ترمینالی
* 🎨 دارای آیکون اختصاصی
* 📂 اضافه شدن به منوی برنامه‌های Kali Linux
* 🔧 نصب آسان با `install.sh`
* 🗑️ حذف آسان با `uninstall.sh`

### 📦 پیش‌نیازها

* Python 3
* `prompt_toolkit`

### 🚀 نصب

ابتدا پروژه را دریافت کنید:

```bash
git clone https://github.com/mrlizard533-cpu/Cyrus-Terminal.git
cd Cyrus-Terminal
```

سپس فایل نصب را اجرایی کنید:

```bash
chmod +x install.sh
```

و نصب را انجام دهید:

```bash
sudo ./install.sh
```

بعد از نصب، **Cyrus Pro** را می‌توانید از منوی برنامه‌های Kali اجرا کنید.

### 🗑️ حذف

برای حذف Cyrus Pro:

```bash
sudo ./uninstall.sh
```

# 🇬🇧 English

## What is Cyrus Pro?

Cyrus Pro is a lightweight terminal application for **Kali Linux**, built with Python and `prompt_toolkit`.

The project aims to provide a simple, fast and easy-to-install terminal environment.

## ✨ Features

* Lightweight and fast
* Built with Python
* Terminal-based interface
* Custom application icon
* Kali Linux application menu integration
* Easy installation with `install.sh`
* Easy removal with `uninstall.sh`

## 📦 Requirements

* Python 3
* `prompt_toolkit`

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/mrlizard533-cpu/Cyrus-Terminal.git
cd Cyrus-Terminal
```

Make the installer executable:

```bash
chmod +x install.sh
```

Install:

```bash
sudo ./install.sh
```

After installation, launch **Cyrus Pro** from the Kali Linux application menu.

## 🗑️ Uninstallation

```bash
sudo ./uninstall.sh
```
