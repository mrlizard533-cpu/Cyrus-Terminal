# 💠 Cyrus Terminal (کورش ترمینال)

**Cyrus Terminal** is a professional, Persianized enhanced terminal interface designed specifically for Kali Linux users. It aims to bridge the language gap and provide instant, high-quality documentation for cybersecurity tools.

## ✨ Features
- **Smart Persian Translations:** Instant offline help for hundreds of Kali tools.
- **Professional UI:** Custom color palette (Turquoise, Gold, Navy).
- **Auto-Completion:** Intelligent system command completion.
- **High Performance:** Lightweight and runs entirely offline.
